# Ember Crema (Cafe Website 1)

Premium client-demo template for a specialty coffee roastery & café. Plain HTML, CSS and JavaScript, no build step.

## Preview
Double-click `index.html`, or serve the folder (better for video autoplay):

    npx serve .

## Customise for a client
- Name, address, phone, WhatsApp number: search `index.html` and `js/main.js` for `98000` and the brand name.
- Opening hours: `HOURS` / `BATCHES` at the top of `js/main.js` (times are read in India time).
- Colours and fonts: the variables at the top of `css/styles.css`.
- Photos and videos: replace files in `assets/img` and `assets/video` with the client's own, keeping the same names.

## Deploy
Drag the folder into Netlify or Vercel, or push it to GitHub Pages. No server code is needed.
